# Security Policy

Bu public demo, üretim ortamından fiziksel olarak ayrılmış bağımsız bir kod tabanıdır. Uzak veri tabanı istemcisi, ağ kütüphanesi, kimlik bilgisi okuyucusu ve şube modeli içermez.

Bir güvenlik sorunu fark edersen gerçek anahtar, kişisel veri veya şirket kaydı paylaşmadan GitHub Private Vulnerability Reporting üzerinden repository sahibine bildir.
